## v1.0.0 - 2026-11-03
### Added
* `ghstat wrapped --output plain` prints the review without colors, columns or charts, to paste into a document or team chat
### Changed
* `ghstat wrapped` counts a security fix only when it traces to you: a Dependabot alert needs every recent change to its manifest to be yours, and code scanning alerts are no longer counted because nothing ties them to who fixed them
