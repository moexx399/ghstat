## v0.1.1 - 2026-10-28
### Fixed
* Each workflow appears once, with its latest run on the branch: runs are grouped by workflow rather than by run name, every active workflow is included even if it last ran long ago, and deleted and disabled workflows are left out.

## v0.1.0 - 2026-10-28
### Added
* Initial release: ghstat shows the latest GitHub Actions run of each workflow and the check runs and commit statuses on each branch's latest commit, for the repos in a config file. It has a TUI for tmux popups (drill into checks, open them in the browser, filter to what needs attention, auto-refresh), a one-shot `list` for the shell, and cached tmux status-bar badges that refresh in the background: `badge` for check results and `badge prs` for open pull requests across all repos, optionally only those updated within `--since` (e.g. 7d). Uses $GH_TOKEN, $GITHUB_TOKEN or `gh auth token`, and supports GitHub Enterprise Server.
